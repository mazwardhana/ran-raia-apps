# Ikon PWA Raia (placeholder)

File di folder ini adalah **placeholder sementara**, bukan logo final. Dibuat
sebagai monogram "R" putih di atas latar `#0F766E` agar PWA tetap layak di-install
sampai aset resmi tersedia.

- `icon-192.png`, `icon-512.png` — `purpose: "any"`, konten ~84% canvas.
- `icon-maskable-192.png`, `icon-maskable-512.png` — `purpose: "maskable"`,
  konten dibatasi ~68% canvas supaya aman saat dipotong Android (safe zone 80%).
- `apple-icon.png` (180×180) — untuk "Add to Home Screen" di iOS.

Ganti semuanya dengan logo resmi begitu tersedia.
